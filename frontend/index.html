Fourteen collections mirror the fourteen BCNF tables one-to-one, with the same field names. Each has a $jsonSchema validator for its column types, lengths and NOT NULLs, and a unique index for its primary key. Foreign-key fields are indexed but not enforced: MongoDB has no FOREIGN KEY, so the shop checks references itself. total_amount still isn't stored on orders; order_totals is a view that runs an aggregation pipeline each time it's read.

Data lives only in this browser tab: an in-browser MongoDB engine (the mingo query library) plus localStorage for your changes. Nothing is sent anywhere — this login is a class-project demo, not real security.
